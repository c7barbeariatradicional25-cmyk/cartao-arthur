# Cartão digital do Arthur Braga — C7 Barbearia Tradicional

Página única (`index.html`) com abertura animada: a navalha e a tesoura brigam e voltam para o lugar delas na logo da C7.

## Onde trocar os dados

No `index.html`, procure o bloco `DADOS DO CARTÃO` (perto do final) e troque o que está marcado com `TROCAR`:
WhatsApp, Instagram, links do Google, endereço, números e textos.

## Publicar

Na Vercel: Add New → Project → `cartao-arthur` → Deploy (não precisa de configuração).
